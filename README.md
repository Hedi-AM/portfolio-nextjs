# portfolio-nextjs

Portfolio Next.js of Hedi Ben Abdelmoumen, generated by the Backstage template `portfolio-nextjs-template`.
Technical documentation: [docs/TECHNICAL.md](docs/TECHNICAL.md)

## Lifecycle (all driven from Backstage)

1. Template `portfolio-nextjs-template` generates the project, Dockerfile, .dockerignore, docker-compose.yml, CI/CD workflow, creates this GitHub repo, sets the Docker Hub secrets and registers the component in the catalog.
2. GitHub Actions builds the Docker image and pushes it to Docker Hub (`hediam/portfolio-nextjs:<version>` and `latest`).
3. Watchtower on the VM detects the new `latest` image and redeploys the container.
4. Template `portfolio-redeploy` re-runs the whole chain with a new version (v2) and applies the evolution (Certifications, Projets DevOps & Cloud, Dark Mode, updated title).

## URL

The spec expects http://localhost:3000. Docker runs only inside the VM and VM port 3000 is used by another project, so the app is published on **http://192.168.122.180:3005**.

Health endpoint: http://192.168.122.180:3005/api/health
